# Simple To-Do List Web Application

A clean, responsive, and user-friendly **To-Do List Application** built using **HTML, CSS, and JavaScript**.  
This project allows users to manage their daily tasks easily with features like adding, editing, deleting, completing, and filtering tasks.  
All tasks are saved automatically in the browser using **localStorage**.

---

##  Features

### 📝 Task Management
- Add new tasks  
- Edit tasks (double-click or ✏️ button)  
- Delete tasks (🗑️ button)  
- Mark tasks as completed  
- Auto-save tasks using localStorage  

### 🔍 Task Filters
- View **All Tasks**  
- View **Active Tasks**  
- View **Completed Tasks**  
- Clear all completed tasks in one click  

###  User Interface
- Clean, modern, minimalistic UI  
- Responsive layout — works on all screen sizes  
- Smooth hover & focus effects  
- Easy to navigate and visually appealing design

## ▶️ How to Run the Project

You can run this project in **two easy ways**:

### 🔹 Method 1 — Open Directly
1. Download the project folder  
2. Locate `todo_list.html`  
3. Double-click to open in your browser  
4. The app will load immediately  

### 🔹 Method 2 — Using VS Code (Live Server)
1. Open project folder in **Visual Studio Code**  
2. Right-click on `todo_list.html`  
3. Select **“Open with Live Server”**  
4. The application will open with auto-refresh  
(*Recommended for development*)
